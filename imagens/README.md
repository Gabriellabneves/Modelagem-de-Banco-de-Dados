# Pasta de imagens

Esta pasta armazena imagens usadas na documentação e diagramas do projeto.

Como usar:
- Coloque arquivos de imagem aqui (por exemplo: .png, .jpg, .svg).
- Para referenciar no README ou outros arquivos Markdown use: `![descrição](imagens/nome-da-imagem.png)`.

Observação: o Git não rastreia pastas vazias — este README existe para garantir que a pasta seja criada no repositório.
